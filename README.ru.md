# Punto для macOS

[English version](README.md)

Punto — локальная menu-bar утилита, которая замечает слово, набранное в русской
раскладке вместо английской (или наоборот), исправляет уже введённый текст и
оставляет включённой правильную раскладку. Она также умеет преобразовывать речь
в нормализованный текст в активном поле любого приложения.

Примеры:

- `ghbdtn ` → `привет `
- `руддщ ` → `hello `

## Как это работает

1. Приложение запоминает текущее слово как последовательность физических
   нажатий (клавиша и Shift/Caps Lock).
2. Оба варианта слова строятся по реальным раскладкам системы через
   `UCKeyTranslate`: по текущей раскладке и по включённой раскладке второго
   языка. Поэтому поддерживаются любые пары, например «США международная (PC)»
   с мёртвыми клавишами и «Русская» Apple, где знаки стоят на цифровом ряду
   (Shift+6 это запятая, Shift+7 точка, `\` это «ё»).
3. Системная проверка орфографии macOS сравнивает исходное слово и вариант.
4. Замена выполняется только когда исходное слово неизвестно, а вариант в другой
   раскладке известен словарю. URL, email, пути, слова с цифрами и ввод с
   Command/Control/Option игнорируются.
5. Текст никуда не отправляется: обработка выполняется локально.

Исправление срабатывает после пробела/Enter/Tab, чтобы приложение увидело слово
целиком. Если сразу после слова нажата клавиша, которая в целевой раскладке
печатает знак препинания, а в текущей не печатает букву, слово исправляется в
момент нажатия знака: `ghbdtn` и Shift+6 дают `привет,` и сразу включают русскую
раскладку. Клавиши `.` и `,` в русской раскладке — буквы `ю` и `б`, поэтому такое
слово исправляется на пробеле, а набранный знак сохраняется (`ghbdtn.` →
`привет.`). Мёртвые клавиши учитываются: нажатие, ожидающее следующей клавиши,
приложение не получает, если слово исправляется на нём.

Проверить слово по своим раскладкам можно без набора:

```sh
/Applications/Punto.app/Contents/MacOS/Punto --check-word 'ghbdtn^'
```

Режим намеренно консервативный: незнакомые имена и технические термины
лучше не менять автоматически.

## Сборка и запуск

```sh
chmod +x scripts/build-app.sh
./scripts/build-app.sh
open dist/Punto.app
```

Если `swift build` не работает (например, после частичного обновления Command
Line Tools), скрипт собирает приложение напрямую через `swiftc` с самым новым
SDK, который принимает установленный компилятор. SDK можно задать явно через
переменную `PUNTO_SDK`.

Детерминированная smoke-проверка раскладки, смешанного распознавания,
пунктуации и веток завершения после сборки:

```sh
.build/release/Punto --self-test
```

Если в установленном toolchain доступен XCTest, полный набор запускается так:

```sh
swift test --disable-sandbox
```

Установка в `/Applications` с перезапуском уже запущенной копии:

```sh
./scripts/install-app.sh
```

При первом запуске macOS попросит разрешить Punto управление компьютером:
**Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**.
После выдачи разрешения приложение начнёт работать; значок «P» появится в строке
меню. Через него автокоррекцию можно приостановить.

### Значок «P» серый, автокоррекция не работает

Серый значок и пункт меню «Нужен доступ к управлению компьютером» означают, что
`AXIsProcessTrusted()` вернул `false` и перехват клавиатуры не запущен. Причина
почти всегда в разрешении Универсального доступа, а не в коде.

Ad-hoc подпись без явного требования (`codesign --sign -`) получает designated
requirement вида `cdhash H"…"`, который меняется при каждой пересборке. macOS
хранит это требование вместе с выданным разрешением, поэтому новая сборка его
теряла, хотя переключатель в настройках оставался включённым. В логе `tccd` это
выглядит так:

```
Failed to match existing code requirement for subject local.punto.autolayout
    cdhash H"<старая сборка>"
    cdhash H"<текущая сборка>"
```

`scripts/build-app.sh` подписывает приложение с требованием
`identifier "local.punto.autolayout"`, которое не зависит от содержимого
бинарника, поэтому разрешение переживает пересборки. Если разрешение всё же
выдано старой сборке, сбросьте запись только для Punto и запустите его заново:

```sh
tccutil reset Accessibility local.punto.autolayout
open /Applications/Punto.app
```

Либо выключите и снова включите Punto в списке Универсального доступа. Проверить
текущее требование подписи можно командой:

```sh
codesign -d -r- /Applications/Punto.app
```

Значок в строке меню и иконка приложения рисуются из одного контура
`Resources/parking.svg` (знак «P»: иконка «parking» из Font Awesome Free 5,
лицензия CC BY 4.0, получена через SVG Repo). Обычный значок подстраивается под
светлую и тёмную строку меню, во время записи он красный, во время обработки
полупрозрачный, при ошибке оранжевый. Иконка приложения собирается в
`build-app.sh` командой `Punto --write-iconset` и `iconutil`.

## Голосовой ввод

1. Поставьте курсор в нужное поле ввода.
2. Нажмите **Option–Space** и говорите. Значок Punto станет красным.
   Сочетание можно сменить в меню **Сочетание клавиш**. Двухклавишные варианты:
   Option–Space, Control–Fn (🌐), Fn (🌐)–Space и Control–Space; трёхклавишные: Control–Option–Space,
   Control–Shift–Space, Command–Shift–Space, Control–Option–D и Control–Option–V.
   Выбор сохраняется между запусками. Сочетание срабатывает только при точном
   наборе модификаторов; Caps Lock не учитывается. Сочетания, которые уже заняты
   в Системных настройках → Клавиатура → Сочетания клавиш (например, Control–Space
   для переключения раскладки), в меню недоступны и подписаны: перехват Punto
   срабатывает раньше системы и отнял бы эту функцию. Пока выбран Option–Space,
   неразрывный пробел через Option–Space не набирается.
   Fn на большинстве сторонних клавиатур (например, Logitech MX Keys) работает
   внутри самой клавиатуры и в Mac не передаётся, поэтому Control–Fn и Fn–Space
   работают только с клавиатурами Apple.
   Control–Fn состоит только из модификаторов и срабатывает при отпускании, если
   между нажатием и отпусканием не было другой клавиши и прошло не больше секунды.
   Поэтому Fn–Control–F2 и другие системные сочетания с этими клавишами работают
   как раньше. Если при этом macOS ещё и переключает раскладку или открывает
   эмодзи, выберите «Ничего не делать» в Системных настройках → Клавиатура →
   «Нажатие клавиши 🌐».
3. Нажмите обычный **пробел**. Punto завершит запись, нормализует пробелы,
   пунктуацию и регистр, затем вставит результат в то же поле. Сам завершающий
   пробел в поле не попадёт.

Повторное нажатие выбранного сочетания также завершает диктовку и остаётся
резервным вариантом. Системная модель может прислать финальный результат раньше,
но Punto сохраняет его и ждёт явной остановки пользователем. Приостановка
автокоррекции во время записи сначала отменяет голосовой ввод, поэтому управление
остановкой не теряется.

Для совместимости со встроенными web-редакторами (Electron/Chromium IDE и
Claude-панели) Punto вставляет результат через системное действие вставки. Старое
содержимое буфера обмена сохраняется и автоматически восстанавливается; если
пользователь успеет скопировать новый текст, Punto его не перезапишет.

При первом использовании macOS попросит разрешения на микрофон и распознавание
речи. Для восстановления ранее запрещённого доступа меню содержит отдельные
пункты настроек распознавания речи и микрофона. В меню языка доступен режим
`Авто: Русский + English`: Punto одновременно распознаёт речь системными
моделями `ru-RU` и `en-US`. macOS 26 допускает только одну активную задачу
распознавания на процесс (вторая отменяет первую), поэтому второй язык
работает во вспомогательном процессе `Punto --recognizer-helper`, который
получает звук по pipe и наследует разрешение на распознавание. Ручной выбор
`Русский` или `English` остаётся доступен для максимальной предсказуемости.
Если в авто-режиме доступна только одна модель, меню явно показывает временный
одноязычный режим. Распознавание выполняет системный Speech framework macOS;
доступность обработки на устройстве зависит от установленных в системе
языковых моделей.

Punto **не переводит смысл текста**: русская речь остаётся русской, английская —
английской. Приложение выбирает только слова, которые фактически вернула одна из
двух системных моделей. Английские термины, названия продуктов и аббревиатуры
внутри русской фразы сохраняются с регистром английского результата, например
`Claude`, `OpenAI` или `API`.

Режим `Авто` рассчитан на русскую речь с английскими терминами (и наоборот).
Сначала по всему тексту выбирается базовый язык: акустическая уверенность
«чужой» модели обычно на порядок ниже. Затем слова второй модели попадают в
результат только локально: слово заменяет перекрывающийся по времени фрагмент
базового языка или заполняет паузу, когда у него есть признаки термина и
достаточная уверенность. Признаки термина: известный термин (`Claude`, `GitHub`,
`API`, `Docker`, `Kubernetes`, `Slack` и другие из встроенного списка),
аббревиатура заглавными, CamelCase, цифры в слове, а также слово базового языка
вне системного словаря (например, `клауд` против `Claude`). Обычные английские
слова русскую речь не вытесняют, даже если английская модель в них уверена.
Решения независимы для каждого слова, поэтому пропуск или склейка слов в одной
из моделей не ломает остальной текст. Свои термины можно добавить в файл
`~/Library/Application Support/Punto/terms.txt`: по одному слову в строке,
строки с `#` игнорируются, файл читается при запуске Punto.

Русские модели Apple (и `SFSpeechRecognizer`, и новый `DictationTranscriber`
в macOS 26) знаков препинания не ставят, английские ставят. Поэтому для текста
без знаков Punto расставляет их сам, а уже пунктуированный английский текст
сохраняет:

- пауза примерно от 0,55 секунды становится запятой, от 1,1 секунды — точкой
  или вопросительным знаком; после конца предложения следующее начинается с
  заглавной буквы;
- запятая ставится после приветствия в начале фразы («Привет, …», «Добрый день, …»),
  перед «но», «а», «однако», «зато», «чтобы», «если», «когда», «потому что» и
  перед союзными словами придаточного в середине фразы («знаю, где», «тот,
  который»), кроме позиций после предлога, «так», «потому», «и», «а» и т. п.;
- вопросительный знак ставится по вопросительному слову в начале фразы или
  после приветствия («Привет, как дела?»), по частице «ли» и по «ты/вы» вместе со
  сказуемым вроде «слышишь», «понимаешь», «готовы», «дома» в конце фразы;
- знаки можно продиктовать словами: «запятая», «вопросительный знак», «знак
  вопроса», «восклицательный знак», «двоеточие», «точка с запятой»,
  «многоточие», а «точка» — в конце фразы или перед паузой (иначе это слово,
  как в «точка зрения»).

Интонацию Punto не анализирует: высота тона, которую отдаёт macOS, на реальных
записях не отличает вопрос от утверждения надёжно. Вопрос без вопросительного
слова и без перечисленных сказуемых («Ты придёшь завтра») получит точку —
продиктуйте «вопросительный знак». Распознаватель почти не оставляет пауз между
предложениями в сплошной речи, поэтому в длинной диктовке без пауз точки внутри
текста не появятся: сделайте паузу около секунды или скажите «точка».

## Диагностика сочетания клавиш

Каждое срабатывание сочетания записывается в системный журнал; для сочетаний из
одних модификаторов туда же пишутся нажатия модификаторов (без набранного
текста). Если в журнале нет кода 63 при нажатии Fn, клавиатура не передаёт Fn в Mac.

```sh
log show --last 5m --predicate 'subsystem == "local.punto.autolayout"' --style compact
```

Проверить работающий Punto без физической клавиатуры можно синтетическим
нажатием; запуск через `open` нужен, чтобы использовать Универсальный доступ Punto.app:

```sh
open -n -a /Applications/Punto.app --args --post-test-shortcut option-space
```

## Диагностика голосового ввода

Punto сохраняет последнюю запись диктовки в
`~/Library/Application Support/Punto/last-dictation.caf` (перезаписывается при
каждом голосовом вводе). Тот же конвейер можно прогнать на любом аудиофайле без
микрофона и посмотреть, что вернула каждая модель и что выбрал сборщик:

```sh
open -n -a /Applications/Punto.app --args \
  --transcribe-file ~/Library/Application\ Support/Punto/last-dictation.caf \
  --out /tmp/punto-report.txt
cat /tmp/punto-report.txt
```

Запуск через `open` нужен, чтобы использовать разрешение на распознавание речи,
выданное Punto.app. Флаг `--fast` подаёт звук быстрее реального времени,
`--only ru-RU` или `--only en-US` оставляет одну модель. Отчёт показывает
частичные и финальные результаты, задержку финала, уверенность каждого слова
и итоговый выбор как при немедленном ответе, так и по таймауту приложения.

## Ограничения MVP

- Поддерживаются раскладки, у которых основной язык английский или русский.
  Используется первая включённая раскладка каждого языка.
- Приложения с защищённым вводом (например, поля пароля) блокируют глобальный
  перехват клавиатуры средствами macOS.
- Точность смены языка и написания терминов ограничена вариантами и временными
  метками, которые возвращают системные модели Speech; Punto не придумывает и не
  переводит отсутствующие в них слова.
- Для распространения вне локального Mac приложение следует подписать Developer
  ID и нотарифицировать.
